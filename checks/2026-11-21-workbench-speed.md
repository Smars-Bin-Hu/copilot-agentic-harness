# 检查：任务页提速 + Super agent 工作台（版本号发布时定，1.8.23 或之后）

在公司电脑上走一遍，每一步拍照发回。不需要真 Copilot 干活；有几个打开的任务就行（最好有一个在等你、一个在工作）。

## 准备

1. 点看板右上角的电源按钮停掉看板。
2. 更新到新版本，运行 `harness --version` 看版本号。
3. 双击 Start Harness，等看板起来。

## 第 1 步：任务页打开快了吗

1. 在 List 里点一个任务名，打开它的任务页（新标签）。**掐表**：从点下去到页面出现用了几秒。
2. 关掉这个标签，再点另一个任务。再掐一次。第二次应该比第一次快（脚本已经在浏览器里了）。
3. 和以前比：以前是 10–20 秒。写下这两次各几秒。
4. 在任务页按 `F12` → **Network**，**不要**勾 Disable cache，按 `F5` 刷新。拍下最下面一行（`requests`、`transferred`、`Finish`）。`transferred` 应该是几十 KB，不再是 1 MB 多。

## 第 2 步：再跑一次测量脚本

和 `checks/2026-11-20-page-speed.md` 第 1 步一样（复制那一大段进 PowerShell）。拍下输出。第 4 行 "task page data" 的 opens 数应该比上次少很多。

## 第 3 步：工作台（宽屏）

1. 点 **Super agent**。整个窗口变成工作台：左边 Waiting for you 和 Agents running，中间聊天，右边 Data 和 Task。拍照。
2. 在左边一张卡上点 **Open task ↗**：任务页在右边 Task 里打开，**没有**新开标签。在里面点一个按钮（比如 Confirm requirement 或换一个页签），应该能用。拍照。
3. 顶上 Left / Right 的四个按钮各点一下：对应的面板关掉、再打开。一边全关时，聊天变宽。拍一张。
4. 鼠标停在 Data 的一行上：弹出任务名、模型、上下文等。拍照。
5. 点 ← 回到看板，再点 Super agent 回来：面板和打开的任务页都还在。

## 第 4 步：Focus 模式

1. 顶上切到 **Focus**：左边只有聊天，右边是 agent 在跑的画面。右下角一张卡（"1 of N"）。拍照。
2. 点 **Later ›**：换下一条。点 **—**：卡收成一个小按钮，再点回来。
3. 在卡上点 **Open task**：任务页在屏幕中间的窗口里打开。按 Esc 关掉。拍照。

## 第 5 步：竖屏

1. 把浏览器窗口拉成又窄又高（比宽还高）。工作台自己变成竖屏布局：底部一排四个图标。拍照。
2. 点 Queue 图标，再在一张卡上点 Open task：任务页叠在下面，聊天还看得见。拍照。

## 第 6 步：慢电脑上的感觉

工作台开着用 2–3 分钟（切模式、开任务、回答一条）。有没有卡顿、风扇转、某个操作要等很久？写一句。

## 发回

每一步的照片；第 1 步的两个秒数；第 6 步的一句话。
