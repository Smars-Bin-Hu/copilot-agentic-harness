# 检查：这台电脑上，一次文件检查、一次列目录、一次打开文件、一次启动程序各要多久

背景：看板（board）现在每 3 秒把所有任务重算一遍。在 Mac 上量到，一次列表要做 1,140 次“文件检查”，一分钟约 7 万次。我们准备把看板改成“变了才算”。动手之前要知道一件从没量过的事：**公司电脑上这些操作每次到底多少毫秒**。它决定先改哪一项。

这次**只量，不改任何东西**。脚本只读文件；唯一写的地方是系统的临时文件夹，跑完自己删掉。

要用的文件：和这份说明在同一个文件夹里的 `2026-11-25-board-cost.py`。把它下载到 harness 文件夹里（有 `.harness` 的那一层）。任何版本的 harness 都可以。

每一步拍照发回。

## 1. 空闲时量一次

关掉 VS Code 和看板，等一分钟，然后在 harness 文件夹里：

```powershell
python .\2026-11-25-board-cost.py
```

大约一分钟，打印三段：

- 第一段三行：文件检查、列目录、打开文件，各一次多少毫秒。
- 第二段：启动一个很小的程序、启动 Python、Python 加载 hook 要的代码、加载命令要的代码，各多久。
- 第三段：同样几个模块，从文件夹加载和从一个压缩包加载，各多久。

拍下整个输出。

## 2. 忙的时候再量一次

开着看板，让 3 到 5 个任务同时在跑（平时干活的样子就行）。在它们跑的时候，另开一个 PowerShell 窗口，同一个文件夹：

```powershell
python .\2026-11-25-board-cost.py
```

拍下整个输出，并写一句当时有几个任务在跑。

## 3. 浏览器到本机的一条长连接能不能保持 10 分钟

新的看板想用一条不断开的连接把变化推给页面。要先知道安全软件或代理会不会把它掐掉。

```powershell
python .\2026-11-25-board-cost.py --stream
```

1. 它会打印一个 `http://127.0.0.1:…` 的地址。用平时开看板的那个浏览器打开它。
2. 页面上每 5 秒多一行计数。放着不动 10 分钟。
3. 10 分钟后拍下页面。上面有：收到几行（应该是 120）、迟到几行、最长的间隔、断了几次。
4. 回到 PowerShell 按 Ctrl+C。

如果页面一开始就写 BROKEN，或者中途停住不动了，也拍下来，这正是我们要知道的。

## 4. 一条命令要多久

在 harness 文件夹里：

```powershell
Measure-Command { harness task list | Out-Null } | Select-Object TotalSeconds
```

连跑三次，拍下三个数。

## 怎么读结果

| 看到什么 | 说明什么 |
| --- | --- |
| 文件检查一次在 0.05 ms 以下 | 检查本身便宜。慢的主要是计算和启动程序，优先改这两样 |
| 文件检查一次在 0.5 ms 以上 | 一分钟 7 万次检查就是 35 秒以上，优先让看板少查文件 |
| “忙的时候”比“空闲时”慢很多倍 | 这些操作会互相排队，看板查文件会拖慢 hook |
| 很小的程序启动比 `python -S` 快很多 | 以后可以考虑把 hook 和命令的启动器换成更小的程序 |
| 从压缩包加载比从文件夹加载快很多 | 安全软件是按“每个文件”花时间的，把代码打成一个包会有用 |
| 长连接 10 分钟没断、没有迟到 | 可以用推送；断了或迟到很多，就用退路（每次最多挂 20 秒的请求） |
