# 检查：第一次打开的设置向导、只有一个按钮的 Enter、设置窗口（目标 1.8.x-onboarding，验收第 7 条）

背景：旧的 Get ready 表单已经删掉。新的做法是：
- 一份新 copy 第一次打开，进一个单独的设置页，一页只配一件事，顶上有进度条。
- 配好以后，Enter 页上只有 HARNESS 和一个按钮。有东西挡着用时，这个按钮就变成修那个东西的按钮。
- 跳过的事情，在齿轮上亮一个小点。
- 齿轮打开"设置"。

Mac 上已经真跑过（证据在 `.local/中心设计思想/1.8.x-onboarding/`）。这里在公司电脑上用一份**全新的 copy** 再走一遍，再看几件只有 Windows 上才有的事：路径、慢的电脑、代理、gh.exe 被拦。

要用的版本：**1.8.32**（main 上打了 tag 的那个；它包含 1.8.30、1.8.31 的全部改动，外加两轮新人走查以后的修正）。**解压到一个新文件夹**，旧的那份不要动。先关掉 VS Code 和旧的 board。第 6b 节是 1.8.32 新加要看的几项。

每一步拍照发回。

## 1. 第一次打开：直接进向导（验收 1）

1. 在新文件夹里双击 `Start Harness.cmd`。
2. 浏览器应该自己到设置页（地址里是 `/setup`），不会停在 Enter。
3. 欢迎页：
   - 列出这台电脑上找到了什么，以及"好了 N 件、还要你做 M 件"。
   - 记下从双击到欢迎页出来用了多久。
4. "你"这一页：
   - git 里设置过名字的，名字已经填好了；
   - 没设置过的，名字框是空的，页面会请你填。

## 2. 程序页（验收 2）

1. Python、Git、VS Code、GitHub CLI、harness 命令，每一行都有找到的路径和版本。路径是 Windows 的，很长的话应该截断，不会撑破版面。
2. 把鼠标停在"found"上，会显示是怎么找到的。
3. 如果 gh 没装、或者被公司拦了：
   - 没装：那一行显示"not found"。
   - 被拦：那一行显示"found, but it will not run"，下面写着原因。
   - 旁边有下载链接，还有一个填文件夹的框；
   - "继续"按不了。
   拍照。
   - **gh.exe 被拦时停在这里，不要想办法绕过去。** 把截图发回来。
4. 电脑很慢时，版本那一格可能先显示"still checking…"，过几秒变成版本号。记下等了多久。

## 3. Copilot 页（验收 3）

想把登录真的走一遍、又不动你现有的 gh 登录，就用一个临时的 gh 设置目录启动：

```powershell
$env:GH_CONFIG_DIR = "$env:TEMP\gh-onboarding"
& ".\Start Harness.cmd"
```

1. 按 **Sign in with GitHub**：页面上出一次性码，还有 Open GitHub、Cancel 和倒计时。
2. 在浏览器里批准。回到设置页，不用刷新，它应该自己翻到下一页。
3. 页面底部那条细线：host 第一次准备时会显示下载进度（约 600 MB）。记下用了多久。
4. 在 host 还没准备好的时候就走到最后一页：Copilot 那一行应该算"已登录"，"确认"能按。
5. 做完以后关掉这个窗口，删掉 `%TEMP%\gh-onboarding`。

## 4. 知识库、代码仓库、清单（验收 3、4）

1. 知识库页：用你们团队的知识库（zip 或文件夹）导入。导入以后有一行图标，说它带来了什么：领域、skill、工具包、连接、代理配方。
2. 知识库带的工具包要用某个程序（比如 sqlcmd、az），而这个程序没找到时，接着出现"工具包要的程序"这一小页：
   - 找不到的有下载链接和填文件夹的框，也可以"以后再说"；
   - 都找到了，这一页就不出现。
3. 知识库带了连接的话，出现"连接"这一小页：每个连接一行，有"登录"按钮，可以先跳过。
4. 代码仓库页：列出常见目录里的仓库，`%USERPROFILE%\source\repos` 也在里面。勾几个，或者"以后再说"。
5. 清单页：
   - 配好的打勾；
   - 没配的每样一句话说影响；
   - 进度条上跳过的那几格是黄点。
6. 按"确认"：进 board，不会又弹回设置页。

## 5. 以后再打开：只有一个按钮（验收 5）

1. 关掉 board，再双击 `Start Harness.cmd`：到的是 Enter，上面只有 HARNESS 和一个按钮。
2. host 还在准备时，按钮上显示百分比。
3. 齿轮上有小点（如果第 4 步跳过了东西）：鼠标停上去，能看到是哪几样、各有什么影响。
4. 拿 gh 的临时登录试一下：用第 3 步那个 `GH_CONFIG_DIR` 再启动一次，删掉那个目录以后再启动。按钮应该变成 **Sign in to Copilot**，登好以后变回 **Enter**。

## 6. 设置（验收 6）

1. 点齿轮，打开设置。左边有：你、程序、Copilot、知识库、工具包、代码仓库、连接、网络、高级。
2. 网络：代理和证书包跟以前一样能做。
3. 高级：改一下 Python 安装命令，按保存，应该很快保存好，不会跑 doctor。
4. 把浏览器窗口拉窄（大约 820 宽）：左边那一列会变成一排小按钮。拍照。

## 6b. 1.8.32 新加要看的几项

1. 欢迎页上是 Enter 页那个机器人（有天线、黑色面罩、两只眼），不是一个白方块配两个绿点；左上角的标跟 board 页头上的一样。
2. 第一次打开 Enter 页，右下角**不会**冒出"这里的动效看起来有点卡 / Motion looks slow here"那张小卡，也没有"按住蓄光"那行小字。等 10 秒再看一眼。之后要是那张小卡出现了，它应该在**左下角**，不挡住右下角那一列按钮。
3. **拍一张 Enter 页的全屏照片。** Mac 上没有 GPU 的浏览器里，背景右边会出现一块方形的亮度接缝，有 GPU 的就没有。公司电脑要是也有这条接缝，就说明那里的浏览器没开硬件加速。
4. 右下角最下面那个滑块按钮：打开的小面板叫"外观"，里面只有主题、渲染、背景，**没有**语言，也**没有**"重启看板"。
5. 设置 → 你：选一种语言，按"保存"：页面会重新加载一次，回来以后语言变了，旁边显示"✓ 已保存"；Enter 页马上就出来，不会空很久。记下从按保存到 Enter 出来用了多久。
6. 设置 → 高级：最下面有"重启看板"；MCP 那一行，当前选中的那一项是实心的，一眼看得出来。
7. 设置 → 工具包：**不再**列出 demotracker 那个示例包。
8. 没有任务的 board：只有一个"新建任务"按钮，"Try the sample"和"Take the 20-minute lesson"都没有了。
9. 设置 → Copilot：只显示"已登录：…"，窗口**不会**自己关掉。
