# 检查：用 GitHub CLI（gh）的登录给 VS Code 自带的 agent host，公司电脑上能不能用 Copilot

背景：不开编辑器窗口，board 直接用 VS Code 自带的 agent host（`code agent host`）。host 要由连接它的程序交一个 GitHub token。Mac 上试过：只有 GitHub 自家应用发的 token 能用（gh 的可以；自建 OAuth 应用、PAT、VS Code 命令行登录都不行）。gh 自己把 token 存在 Windows 凭据管理器里，重启也不丢，board 每次启动时用 `gh auth token` 取一次就行。

这次想弄清楚三件事：

1. gh 的免安装 zip 版在公司电脑上能不能下载、能不能运行。
2. 公司账号能不能用 gh 登录（组织会不会要求批准这个应用）。
3. 用 gh 的 token，独立 agent host 里的 Copilot 有没有模型、能不能对话。公司关掉的是 Copilot CLI，这里 host 报的是 VS Code 的身份，gh 只提供 token，所以结果说不准，要实测。

**会用到一点 Copilot 额度**：两轮极短的对话（让模型回一个词），用 Haiku。

**如果 gh.exe 被拦**（弹窗说被管理员阻止、杀毒或 EDR 提示），就停在那一步，拍照发回，不要设法绕过：那说明这条路要经过 IT。

## 第 1 步：下载 gh 的 zip（浏览器）

1. 打开 https://github.com/cli/cli/releases/latest
2. 在 Assets 里下载 `gh_<版本>_windows_amd64.zip`（注意是 **zip**，不是 msi）。
3. 解压到 `%USERPROFILE%\tools\gh`，解压后应该有 `%USERPROFILE%\tools\gh\bin\gh.exe`。

## 第 2 步：gh 能不能运行

```powershell
& "$env:USERPROFILE\tools\gh\bin\gh.exe" --version
```

应该显示 `gh version 2.x.x (...)`。拍下结果。

## 第 3 步：用公司账号登录 gh

```powershell
$env:HTTPS_PROXY = "http://127.0.0.1:9000"
$env:HTTP_PROXY  = "http://127.0.0.1:9000"
& "$env:USERPROFILE\tools\gh\bin\gh.exe" auth login --hostname github.com --git-protocol https --web
```

- 它会显示一个一次性的码，按回车后打开浏览器，输入这个码，用公司账号批准。
- 如果问 `Authenticate Git with your GitHub credentials?`，回答 **n**（不改 Git 的设置）。
- 浏览器上如果出现组织相关的提示（例如要求组织批准、SSO 授权），拍下来。
- 成功时最后一行是 `Logged in as ...`。拍下整个窗口（账号名可以遮住）。

## 第 4 步：取探针脚本

在同一个 PowerShell 窗口里：

```powershell
Invoke-WebRequest -Proxy http://127.0.0.1:9000 -OutFile "$env:USERPROFILE\gh-token-probe.py" `
  https://raw.githubusercontent.com/Smars-Bin-Hu/copilot-agentic-harness/pc-tests/checks/2026-11-22-gh-token-probe.py
```

只用 Python 标准库。它从 gh 取 token，只在连接里交给 host，不打印、不保存。

## 第 5 步：运行

还是同一个窗口（代理变量要在）：

```powershell
python "$env:USERPROFILE\gh-token-probe.py"
```

- 它会启动一个独立的 agent host（用 11-21 那次的文件夹 `%USERPROFILE%\agent-host-probe`，server 包已经下好了），交 token，数模型，跑一轮对话；然后重启 host，再取一次 token、再来一遍。
- VS Code 开着或关着都可以，探针不碰正在用的 VS Code。
- 拍下全部输出。Mac 上的样子：

  ```text
  [1] OK    Python 3.9.6, darwin
  [2] OK    gh runs: gh version 2.102.0 (2026-09-30)
  [3] OK    gh is signed in (token kind gho)

  --- first start ---
  [4] OK    agent host ready in 3 s
  [5] OK    connected; before sign-in: 0 Copilot models
  [6] OK    after handing the gh token: 17 Copilot models: auto, claude-sonnet-5.5, ...
  [7] OK    turn complete in 2.2 s with claude-haiku-5.5, reply 'pong'

  --- after a host restart ---
  [4] OK    agent host ready in 3 s
  [5] OK    connected; before sign-in: 0 Copilot models
  [6] OK    after handing the gh token: 17 Copilot models: auto, claude-sonnet-5.5, ...
  [7] OK    turn complete in 2.5 s with claude-haiku-5.5, reply 'pong'

  Done. The probe host is stopped. ...
  ```

## 怎么看

| 结果 | 说明 |
| --- | --- |
| `[6]` 有十几个模型，`[7]` 两轮都 OK | 通了：board 可以用 gh 的登录，不开编辑器，重启也不用重新登录 |
| `[6]` 是 0 个模型，或者只有 `auto` | Copilot 不认 gh 的 token。脚本会打印 host 日志里相关的几行，一起拍下来 |
| `[7]` 报错，带 `policy` 或 `not authorized` | 公司的 Copilot 策略挡了这种组合 |
| `[2]` 或 `[3]` 就失败 | gh 本身用不了（被拦或登录不了），这条路要经过 IT |

## 发回

- 第 2、3、5 步的照片（账号名可以遮住）。
- 第 3 步浏览器里有没有组织批准或 SSO 的提示。

## 做完以后

- 探针结束时已经停掉了它启动的 host。可以删掉 `%USERPROFILE%\gh-token-probe.py`。
- gh 先留着，结果出来再说。如果要撤掉：`& "$env:USERPROFILE\tools\gh\bin\gh.exe" auth logout`，再删掉 `%USERPROFILE%\tools\gh` 文件夹。
