# 检查：时限跟着电脑速度走（1.8.15）

在公司电脑上走一遍。每一步拍照发回。

## 准备

1. 点看板右上角的电源按钮停掉看板。
2. 更新到 1.8.15，运行 `harness --version`，应该显示 `1.8.15`。

## 第 1 步：倍数

1. 双击 Start Harness，等看板起来。
2. 在 harness 文件夹的 PowerShell 里运行 `harness doctor`，看第二行：应该是"时限 ×N（这台电脑起一个 Python 进程用了 X 秒…）"。拍照。记下 N 和 X。

## 第 2 步：VS Code

VS Code 开着时启动看板。Enter 页 VS Code 那一行：
- 应该是黄色"open, getting ready"，一直到连上变绿；
- 记下多久变绿；
- 如果变红（"VS Code has been open for …"），拍照，然后运行下面这条，拍结果：

```powershell
Measure-Command { code agent endpoints | Out-Host }
```

## 第 3 步：doctor 和 Enter

- doctor 那一行多久变成 `no errors`，有没有出现 "no answer in … s"。拍照。
- 全绿以后 Enter 能点。拍照。

## 第 4 步：再双击、重启

1. 看板开着时再双击 Start Harness：浏览器打开已有的看板，看板不重启。
2. 在看板设置里点 Restart board：页面等它回来，不应该出现"看板没回来"。拍照。

## 第 5 步：外部系统和连接

在 Tools 窗口里点一个连接的 Test，看它是不是还会显示"超时"。拍照。

## 发回

每一步的照片，第 1 步的 N 和 X，第 2 步变绿用的时间。
