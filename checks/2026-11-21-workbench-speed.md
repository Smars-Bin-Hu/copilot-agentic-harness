# 检查：任务页提速 + Super agent 指挥台（1.8.25 或之后）

在公司电脑上走一遍，每一步拍照发回。不需要真 Copilot 干活；有几个打开的任务就行（最好有一个在等你、一个在工作）。

## 准备

1. 点看板右上角的电源按钮停掉看板。
2. 更新到新版本，运行 `harness --version` 看版本号。
3. 双击 Start Harness，等看板起来。

## 第 1 步：任务页打开快了吗

1. 在 List 里点一个任务名，打开它的任务页（新标签）。**掐表**：从点下去到页面出现用了几秒。
2. 关掉这个标签，再点另一个任务。再掐一次。第二次应该比第一次快（脚本已经在浏览器里了）。
3. 和以前比：以前是 10–20 秒。写下这两次各几秒。
4. 在任务页按 `F12` → **Network**，**不要**勾 Disable cache，按 `F5` 刷新。拍下最下面一行（`requests`、`transferred`、`Finish`）。`transferred` 应该是几十 KB，不再是 1 MB 多。

## 第 2 步：再跑一次测量脚本

和 `checks/2026-11-20-page-speed.md` 第 1 步一样（复制那一大段进 PowerShell）。拍下输出。第 4 行 "task page data" 的 opens 数应该比上次少很多。

## 第 3 步：指挥台（宽屏）

1. 点 **Super agent**。整个窗口变成指挥台：四周一圈细的绿色光边；看不到看板的搜索、名字、终端、stop、右侧圆按钮。拍照。
2. 中间顶上是"桥"：super agent 连到每个任务的头像，在跑的 subagent 是头像下的小圆点。点一个头像：输入框上方出现 "To: <任务名>"，写一句话发出去，应该进这个任务的对话。拍照。
3. 左边一张卡上点 **Allow · deny** 或 **View**：弹出的对话框在最上面、能用。拍照。
4. 左边卡上点 **Open task ↗**：任务页在右边 Task 里打开，没有新开标签。
5. 面板标题右边的 **—**：面板收起；一边两个都收起就变成一条窄边，点图标还原。拖动左右两条分界线改宽度，刷新页面后宽度还在，双击分界线还原。拍照。
6. 左上角 **—**：回到普通看板，右下角有一个发光的小球 "Super agent · N wait"，点它回来，一切照旧。拍照。
7. 顶栏名字右边的电池：点开，看到 "N of M Credits left today" 和 **Recharge +25 / +50**。按一次 +25，应该写 "+25 added today"。拍照。（这是今天有效的额外额度，明天自动回到原来的上限。）

## 第 4 步：Data 面板

右边 Data 从上到下：Needs a look、Waits on you（按要你做的决定排序的横条）、Pipeline（每种任务一行箭头形的步骤，等你最多的那一步亮）、Where the time goes、Spend。鼠标停在一个小圆点上看任务的详细信息。拍照。

## 第 5 步：Focus 和竖屏

1. 右上角 **FOCUS**：只剩聊天和右边的大画面，右下角一张卡（"1 of N"、Later ›、—）。在卡上点 Open task：任务页在屏幕中间的窗口里，Esc 关掉。拍照。
2. 把浏览器窗口拉成比宽还高：变成竖屏布局，底部四个图标。点 Queue，再在卡上点 Open task：任务页叠在下面，聊天还看得见。拍照。

## 第 6 步：慢电脑上的感觉

指挥台开着用 2–3 分钟（切模式、开任务、回答一条）。有没有卡顿、风扇转、某个操作要等很久？写一句。

## 第 7 步：玩过之后改的几处（第四轮）

1. **Off work 药丸**：看板顶上现在是一个小药丸 ☾ N / ☀ N。把鼠标放上去看说明。记下 List 里显示"等你"的任务有几个，点 ☾：这些任务应该全部变成暂停（只留真正在工作的和开着 autorun 的），弹出的话里没有命令。再点 ☀ 取回。拍照。
2. **点方块回 All**：指挥台里先点桥上一个任务头像（出现 "To: <任务>"），再点桥中央的 super agent 方块：回到 All，"To:" 消失。
3. **小窗口**：点顶栏的弹出按钮（Chrome / Edge）。小窗口里没有机器人、没有标题；顶上四个带颜色的数字；中间是聊天；右上角 ☰ 上有橙色数字，点它收起 / 展开那张"等你"的卡片。把小窗口拖大或拖小，再点 ☰ 几次：**大小不应该变回去**。点卡片上的 **Open ↗**：浏览器里的指挥台到前面，并在右边打开那个任务。拍照。（如果公司策略不让开小窗口，按钮是灰的，悬停会说原因，写一句就行。）
4. **View 弹窗**：左边队列里找一张有 **View** 的卡（被拦的调用），点 View，拍照；再在右边打开同一个任务的任务页，点那里的 View，拍照。两个弹窗应该一样。
5. **Steer**：有任务卡住（Stuck）时，卡上点 **Steer…**，输入几个字，**再点一次 Steer…**：输入框不应该关、字还在；旁边有 **Send**。
6. **慢的批准不挡页面（最重要）**：找一个等你批准的任务（Approve plan、Confirm requirement 或 Approve promote；promote 最慢，最好用它）。点按钮，输入确认码，点 Confirm，**掐表**：
   - 弹窗几秒后关掉的？（应该 1 秒内。）
   - 弹窗关掉后，那张卡的按钮是不是写着 **Working…**？
   - 这段时间里在聊天框发一句话、点别的卡上的按钮：能用吗？
   - 从点 Confirm 到这张卡消失（批准完成）一共几秒？
   - 故意输错一次确认码：过一会儿弹窗应该自己回来，里面有你输的码和原因。

## 发回

每一步的照片；第 1 步的两个秒数；第 6 步的一句话；第 7 步第 6 条的几个秒数和回答。
