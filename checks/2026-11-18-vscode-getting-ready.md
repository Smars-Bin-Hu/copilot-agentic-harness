# 检查：VS Code 开着时，看板说"已打开，准备中"（1.8.8）

1.8.7 里，VS Code 已经开着，看板却说"没打开"，1–2 分钟后才变绿。1.8.8 起：窗口开着、看板还没连上时，VS Code 一行是黄色"已打开，准备中"，写着已等多久；VS Code 一准备好，几秒内变绿。每一步拍照发回。

## 准备

1. 更新到 1.8.8（文件夹更新或 `git pull`）：

   ```powershell
   harness --version
   ```

   应该显示 `1.8.8`。拍照。

2. **完全关掉 VS Code**（File > Exit，所有窗口）。停掉看板（终端里 Ctrl+C）。

## 第 1 步：先开看板，再手动开 VS Code

1. 用 Start Harness 启动看板。停在 Enter 屏，VS Code 一行应该是红色"没打开"。
2. 等 2 分钟（让看板的等待拉长，像 1.8.7 那次一样）。
3. **自己**从开始菜单打开 VS Code 和 harness 文件夹，不要点看板上的按钮。记下打开的时间。
4. 10 秒内看 Enter 屏：VS Code 一行应该变成黄色**"已打开，准备中"**，下面写"VS Code 已经开着……已等 N 秒"，秒数会往上走。**不应该**再出现红色"没打开"。拍照。
5. 等它变绿。记下变绿的时间。拍照。

发回：打开 VS Code 到变绿用了多久；中间有没有出现"没打开"或"code 命令回答得慢"。

## 第 2 步：点看板的按钮打开

1. 再完全关掉 VS Code。
2. 在 Enter 屏点 **打开 VS Code**。
3. 和第 1 步一样：应该是黄色"已打开，准备中"加秒数，然后变绿。记下用了多久，拍照。

## 第 3 步：3 分钟还没好（碰到再拍）

如果"已打开，准备中"超过 3 分钟：应该转红，写"VS Code 已经开了 3 分……还是不让看板接入"，旁边有"重启 VS Code"。拍下来。点它，记下重启后多久变绿。

## 怎么读

| 看到的 | 说明 |
| --- | --- |
| 黄色"已打开，准备中"，1–2 分钟内变绿 | 修好了。剩下的时间是 VS Code 自己在启动。 |
| 窗口开着，却仍是红色"没打开" | 看板没看到 VS Code 窗口。拍下来，告诉我 VS Code 是怎么打开的。 |
| 一直是"code 命令回答得慢"，没有"已打开" | 同上：窗口检查没生效。 |
| 每次都到 3 分钟转红 | VS Code 本身连不上。请跑另一份检查 `2026-11-18-vscode-not-found.md`。 |
